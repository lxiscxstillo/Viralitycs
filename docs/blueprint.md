# **App Name**: RumorSim

## Core Features:

- Initial Conditions Input: Input fields for population size (N) and initial rumor spread (R0).
- Observed Data Input: Editable table to input observed data points (time, number of people who know the rumor).
- Rate Calculation: Calculates the rumor spread rate (k) by fitting the logistic equation to the observed data using curve fitting.
- Results Display: Displays the calculated rate of rumor spread (k). Presents both the analytical and numerical solutions, alongside observed data.
- Comparative Visualization: Generates a comparison graph visualizing the analytical solution, numerical solution (Euler's method), and the observed data points.

## Style Guidelines:

- Dark theme with neon green (#39FF14) as the primary accent color.
- Secondary accent colors include neon blue (#1E90FF) and neon purple (#8A2BE2).
- Use a dark background (#121212) to enhance the neon colors.
- Modern sans-serif font.
- Use rounded borders and smooth visual effects.
- Subtle hover effects and animations to enhance user interaction.
